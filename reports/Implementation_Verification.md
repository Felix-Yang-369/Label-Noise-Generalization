# 实施与结果验收

已完成当前十候选调参和 45 次主实验，冻结后统一评估 2,709 条真实标签测试样本。
17 项测试全部通过；其中最终实际数据验收使用独立混淆矩阵算法复算 45 次指标。

通过项目：
- 原始 ZIP CRC/SHA-256 与 ZIP 内 XLSX 成员内容一致。
- 精确去重 68 条，13,543 个唯一特征样本；三个 split 的原始 row_id 无重叠。
- CSV 特征与原始 XLSX 对应行逐值一致，row_id 不进入模型。
- 实际环境与固定版本兼容；pip check 无冲突；代码和参数有 hash。
- 训练集 EDA 不读取测试；Scaler 的均值核对只来自训练集。
- 噪声标签共有 15 份，同条件三模型共用；实际改变率与预测记录一致。
- 每个完成 run 的模型、逐行预测、trace 与 meta checksum 均核对。
- 45 次 Macro-F1、Accuracy、Balanced Accuracy、clean-target gap 独立复算一致。
- 三种子 mean/sample SD 与 15 条件汇总一致。
- 六个预设代表模型（seed 17，p=0/1，三模型）重新加载推理，类别和概率与保存记录一致。
- 参数/代码/依赖/数据冻结先于主训练；最终评估时间晚于所有主 fits 完成。
- 四张结果图、三张 EDA 图已逐张目视检查；本地 HTML 导航链接通过文件存在检查。

独立审查发现的三处 Important 问题均先加失败测试再修复，并在新版本下重新调参。
原初版记录作为历史单独保留，不进入当前结果。结果没有来自计划预填的性能值。
单类合成测试有一条 sklearn UserWarning，不属于七类真实实验异常。
实际模型的收敛警告及预算限制保存在 meta.json 和结果报告，不能当作无限预算能力结论。
